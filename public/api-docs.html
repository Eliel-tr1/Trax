TRAX CRM - דוקומנטציית API

ממשק REST אחיד לכל האובייקטים במערכת. נוצר אוטומטית מתוך קוד ה-API עצמו, תמיד מעודכן.

אובייקטים: customers | sales | journeys | registrations | tasks | contacts

סקירה כללית

ה-API חושף פעולות CRUD על כל אובייקט במערכת בכתובת אחת, לפי התבנית /api-v1/{object}/{id}. כל אובייקט תומך בחמש פעולות: רשימה, רשומה בודדת, יצירה, עדכון ומחיקה (מחיקה היא מחיקה רכה, הרשומה מסומנת כ-deleted_at ואינה נמחקת פיזית).

כתובת בסיס:

https://bkjqwroclpefwtyxjfkl.supabase.co/functions/v1/api-v1
כל התעבורה ב-HTTPS. אין צורך בהרשאות נוספות מעבר למפתח ה-API.

אימות (Authentication)

כל בקשה חייבת לשאת מפתח API בכותרת Authorization:

Authorization: Bearer <YOUR_API_KEY>
content-type: application/json

מפיקים מפתח במערכת: הגדרות ← מפתחות API ← הפקת מפתח. המפתח המלא מוצג פעם אחת בלבד בעת ההפקה, יש לשמור אותו במקום מאובטח. במערכת נשמר רק ה-hash שלו.

לכל מפתח יש תפקיד (role):

תפקידמיועד ל
readאינטגרציות בקריאה בלבד
writeאינטגרציות שקוראות וכותבות
internalשימוש פנימי של המערכת

מפתח לא תקין או לא פעיל מחזיר 401 עם {"error":"invalid or inactive API key"}.

פרמטרים לשאילתת רשימה (GET)

פרמטרמשמעותברירת מחדל
limitמספר רשומות מקסימלי (עד 200)50
offsetדילוג על רשומות (עימוד)0
sortמיון לפי שדה; -field למיון יורדלפי הסדר הטבעי
<field>=valueסינון לפי כל שדה של האובייקט (התאמה מדויקת)-

סינון לפי שדה שאינו קיים באובייקט מחזיר 400 unknown filter field.

דוגמת רשימה עם סינון, מיון ועימוד

curl -X GET \
  "https://bkjqwroclpefwtyxjfkl.supabase.co/functions/v1/api-v1/customers?status=%D7%9C%D7%99%D7%93%20%D7%97%D7%93%D7%A9&sort=-created_at&limit=20&offset=0" \
  -H "Authorization: Bearer $TRAX_API_KEY"

מבנה תשובה ושגיאות

הצלחה: גוף JSON עם מפתח data. ברשימה מתווסף גם count (המספר הכולל, לפני עימוד).

{ "data": [ { "id": "...", "first_name": "..." } ], "count": 128 }

שגיאה: גוף JSON עם error, ולעיתים גם code (קוד Postgres).

{ "error": "unknown field(s): foo", "code": "PGRST204" }
קודמתי
400גוף JSON לא תקין, שדה לא מוכר בגוף, או שדה סינון לא מוכר
401חסר מפתח API, או מפתח לא תקין / לא פעיל
404אובייקט לא מוכר, או רשומה לא נמצאה
405מתודה לא נתמכת לנתיב (למשל POST ל-/{id})
409הפרת ייחודיות (23505)
422הפרת אילוץ תקינות (23514, למשל ערך לא ברשימה מותרת)
500שגיאה פנימית

נספח: קליטת לידים מהטפסים

נקודת קצה נפרדת לקליטת ליד מטופס באתר, דף נחיתה או Xcon. היא מבצעת נירמול טלפון, זיהוי לקוח קיים, פתיחת עסקה חדשה ורישום הערת הטופס, ואז כותבת דרך אותו API. אינה דורשת מפתח API (משמשת אתרי טפסים).

יצירת ליד POST /functions/v1/lead-intake

curl -X POST \
  "https://bkjqwroclpefwtyxjfkl.supabase.co/functions/v1/lead-intake" \
  -H "content-type: application/json" \
  -d '{
    "full_name": "ישראל ישראלי",
    "phone": "050-1234567",
    "email": "israel@example.com",
    "message": "מתעניין בטיול",
    "form_id": "site",
    "utm_source": "facebook"
  }'
שדהחובההערות
full_nameכןשם מלא
phoneכןמנורמל אוטומטית
emailלא-
messageלאנשמר כהערה על הלקוח ועל העסקה
form_idכןsite | landing | xcon
utm_source, utm_medium, utm_campaign, utm_content, utm_termלאשיוך מקור
page_urlלאכתובת העמוד ששלח

תשובה בהצלחה: 201 עם {"success":true,"customer_id":"...","sale_id":"..."}.
