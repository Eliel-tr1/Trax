# Trax

A standalone CRM for **TRAX Adventure Club** (premium adventure-travel
club) and its founder's second business unit, **Xcon** (SAP consulting) —
replacing Origami as the system of record. React + Supabase, modeled on
Vitrue's `bina-crm` architecture.
